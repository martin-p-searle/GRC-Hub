# TechSecure Solutions: NIST Cybersecurity Framework Project (Fictional)

## Overview
TechSecure Solutions is a fictional U.S.-based technology firm providing cloud services to small businesses. This project applies the NIST Cybersecurity Framework (CSF) to protect customer data and practise cybersecurity governance, risk management and compliance.

## Purpose
A self-directed training project for educational and portfolio purposes. All people, systems and evidence are invented.

## Contents
- [NIST CSF Fundamentals](compliance/nist-csf-fundamentals.md)
- [Cybersecurity Policy](policies/cybersecurity-policy.md) (written against CSF 1.1)
- [NIST CSF Implementation Plan](implementation/nist-csf-plan.md)
- [Security Controls](security-measures/security-controls.md)
- [CSF 2.0 Maturity Assessment](TechSecure-NIST-CSF-Maturity-Assessment.pdf): scores TechSecure's practice against its own policy across all six functions, with priority gaps and a roadmap

## Notes
- The policy, plan and controls use CSF 1.1 (five functions). The maturity assessment uses CSF 2.0, which adds the Govern function.
- Updating the policy to CSF 2.0 is a planned next step.
- This is a fictional project for educational purposes.
